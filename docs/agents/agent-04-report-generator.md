# Agent 04: Report Generator 📊

## 1. Role
Compiles results from all agents into professional reports (PDF and Veo video summary) for the creator (Unlikely Hero) and brand partners. It translates complex data into digestible, actionable insights.

## 2. System Prompt
```text
You are the Report Generator for Crewmate, an elite professional report writer specializing in creator-brand relationships. Your job is to synthesize complex data from contract reviews, compliance checks, and revenue analyses into clear, professional, and visually appealing summaries. You create structured content for PDF reports and engaging scripts for video summaries. Your tone is authoritative, reassuring, and highly polished, ensuring the creator feels fully informed and in control.
```

## 3. Input Schema
```python
from pydantic import BaseModel
from typing import Optional, Any

class ReportInput(BaseModel):
    report_type: str # 'compliance_summary', 'contract_review', 'weekly_digest', 'brand_deliverable'
    contract_analysis: Optional[Any] = None
    compliance_result: Optional[Any] = None
    revenue_insight: Optional[Any] = None
    period: Optional[str] = None
```

## 4. Output Schema
```python
class ReportSummaryStats(BaseModel):
    total_issues_flagged: int
    potential_revenue_unlocked: float
    overall_health_score: int

class FleetReport(BaseModel):
    report_id: str
    pdf_url: str
    video_url: Optional[str] = None
    compliance_score: int
    summary_stats: ReportSummaryStats
```

## 5. Report Types
- `compliance_summary`: Overview of brand safety and FTC compliance.
- `contract_review`: Deep dive into legal clauses and negotiation points.
- `weekly_digest`: High-level summary of all fleet activities.
- `brand_deliverable`: Sanitized report formatted specifically for the brand partner.

## 6. Tools
- `compile_report(data_sources: dict) -> dict`: Merges data from Contract Reviewer, Compliance, etc.
- `generate_pdf(report_data: dict, template: str) -> str`: Uses a library (like ReportLab or HTML-to-PDF) to generate a branded PDF and uploads to Firebase Storage, returning the URL.
- `call_veo(summary_text: str, style: str) -> str`: Calls the Google Veo API to generate a 30-second executive summary video. (+0.2 Bonus)
- `format_for_brand(report: dict, brand_name: str) -> dict`: Strips internal creator-only insights and formats the report for external delivery.

## 8. PDF Template Structure
1. **Header**: Crewmate Logo, Creator Name, Date, Report Type.
2. **Executive Summary**: High-level overview (generated by Gemini).
3. **Compliance & Safety Score**: Visual gauge (e.g., 95/100).
4. **Risk Summary**: Bullet points of critical issues (e.g., "Non-compete clause too broad").
5. **Revenue Insights**: Projected ROI and negotiation leverage.
6. **Recommendations**: Next steps for the creator.
7. **Footer**: Confidentiality notice.
